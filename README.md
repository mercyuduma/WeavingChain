# WeavingChain

A decentralized textile weaving and fiber arts reward system for incentivizing traditional textile craftsmanship on Stacks blockchain.

## Features

- Weaving activity tracking with pattern complexity-based rewards
- Weaver textile level progression with mastery bonus multipliers
- Weaving token accumulation and redemption system
- Thread preservation mechanism with time-based penalties
- Comprehensive loom statistics and analytics

## Smart Contract Functions

### Public Functions
- `start-weaving-activity` - Begin textile weaving session
- `complete-weaving-project` - Complete project and earn rewards
- `claim-weaving-rewards` - Claim accumulated weaving tokens
- `preserve-thread` - Preserve thread for enhanced rewards
- `release-preserved-thread` - Release preserved thread with potential penalties

### Read-Only Functions
- `get-weaving-activity-count` - Get user's total weaving activities
- `get-weaving-token-balance` - Get user's weaving token balance
- `get-textile-level` - Get user's textile mastery level
- `get-loom-stats` - Get overall loom statistics

## Reward System
- Base reward: 22 tokens per project
- Textile bonus: 8 tokens per level (max level 12)
- Thread preservation multiplier: 4x for preserved thread
- Loom capacity: 1.8M total tokens

## Usage

Deploy the contract to create a weaving system where textile artists can track their fiber arts activities, earn rewards, and preserve thread for enhanced benefits.
